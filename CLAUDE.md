# Personal Website

A simple personal website hosted on GitHub Pages. Inspired by the aesthetic of old-school utility websites like voidtools.com — clean, minimal, no bloat.

## Design
- Plain HTML + CSS only. No JavaScript frameworks, no build tools.
- White/light background, simple typography (system fonts), minimal color.
- Looks like a classic documentation/personal site from the early 2000s.
- No animations, no gradients, no cards, no flexbox tricks. Keep it boring.
- Minimal JavaScript only if needed for simple UI interactions (e.g. a collapsible section or copy button). No frameworks — vanilla JS only.

## Structure
Single page with these sections:
- Header with my name and simple nav links
- About Me section (short bio paragraph)
- Projects section (plain list of projects with links)
- Resume link (direct link to PDF or GitHub)

## Hosting
GitHub Pages. Output must be plain static files — no server-side code, no npm, no build step.

## Tone
Personal, straightforward. Not trying to impress anyone with the design.
